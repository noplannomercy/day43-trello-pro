# Day 43: Trello Pro - Software Requirements Specification (SRS)

## 1. 개요

### 1.1 목적
본 문서는 Trello Pro 프로젝트 관리 서비스의 소프트웨어 요구사항을 정의합니다.

### 1.2 범위
- **제품명**: Trello Pro
- **대상**: 소규모 팀(1-5명) 및 개인 프로젝트 관리자
- **기반**: Day 42 Trello Clone 확장

### 1.3 정의 및 약어
- **Board**: 프로젝트 단위의 작업 공간
- **List**: 보드 내 작업 단계 (예: To Do, In Progress, Done)
- **Card**: 개별 작업 항목
- **Label**: 카드 분류를 위한 색상 태그
- **P0/P1/P2**: 기능 우선순위 (0=필수, 1=중요, 2=개선)

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 인증 및 사용자 관리 (P0)

#### FR-1.1 Google OAuth 로그인
- **설명**: 사용자는 Google 계정으로 로그인할 수 있어야 함
- **입력**: Google OAuth 인증
- **출력**: 로그인 성공 시 메인 대시보드 이동
- **제약**: NextAuth 사용

#### FR-1.2 세션 관리
- **설명**: 로그인 상태를 유지하고 세션을 관리
- **동작**:
  - 로그인 후 세션 생성
  - 브라우저 종료 후 재방문 시 로그인 상태 유지
  - 로그아웃 기능 제공

#### FR-1.3 사용자 프로필
- **설명**: 사용자 이름, 이메일, 프로필 이미지 표시
- **데이터**: Google 계정에서 가져온 정보 사용

### 2.2 멀티 보드 관리 (P0)

#### FR-2.1 보드 생성
- **설명**: 새로운 프로젝트 보드를 생성
- **입력**: 보드 이름 (필수), 배경색/이미지 (선택)
- **출력**: 생성된 보드로 자동 이동
- **검증**: 보드 이름 1-100자

#### FR-2.2 보드 목록 조회
- **설명**: 사용자가 소유한 모든 보드 목록 표시
- **출력**:
  - 보드 썸네일
  - 보드 이름
  - 최근 수정 시간
  - 카드 개수
- **정렬**: 최근 수정 순

#### FR-2.3 보드 선택 및 전환
- **설명**: 보드를 선택하여 해당 보드의 내용 표시
- **동작**:
  - 보드 클릭 시 해당 보드 페이지로 이동
  - URL: /board/[boardId]

#### FR-2.4 보드 수정
- **설명**: 보드 이름, 배경 변경
- **입력**: 새로운 보드 이름 또는 배경
- **권한**: 보드 소유자만 가능

#### FR-2.5 보드 삭제
- **설명**: 보드와 포함된 모든 리스트/카드 삭제
- **동작**:
  - 삭제 확인 모달 표시
  - 확인 시 영구 삭제 (복구 불가)
- **권한**: 보드 소유자만 가능

### 2.3 리스트 관리 (P0 - Day 42 유지)

#### FR-3.1 리스트 생성
- **설명**: 보드 내 새로운 리스트 생성
- **입력**: 리스트 제목 (필수)
- **위치**: 기존 리스트 오른쪽 끝에 추가
- **검증**: 제목 1-100자

#### FR-3.2 리스트 수정
- **설명**: 리스트 제목 변경
- **동작**: 제목 클릭 시 인라인 편집 모드

#### FR-3.3 리스트 삭제
- **설명**: 리스트와 포함된 모든 카드 삭제
- **동작**: 삭제 확인 후 실행

#### FR-3.4 리스트 순서 변경
- **설명**: 드래그앤드롭으로 리스트 순서 변경
- **라이브러리**: @dnd-kit 사용

### 2.4 카드 관리 (P0 - Day 42 유지 + 확장)

#### FR-4.1 카드 생성
- **설명**: 리스트 내 새로운 카드 생성
- **입력**:
  - 카드 제목 (필수)
  - 설명 (선택)
- **위치**: 리스트 하단에 추가
- **검증**: 제목 1-200자

#### FR-4.2 카드 조회
- **설명**: 카드 클릭 시 상세 정보 표시
- **표시 정보**:
  - 제목
  - 설명
  - 라벨 (P1)
  - 마감일 (P1)
  - 할당된 멤버 (P2)
  - 활동 로그 (P2)

#### FR-4.3 카드 수정
- **설명**: 카드 정보 수정
- **수정 가능 항목**:
  - 제목
  - 설명
  - 라벨 추가/제거
  - 마감일 설정/변경
  - 멤버 할당/해제

#### FR-4.4 카드 삭제
- **설명**: 카드 영구 삭제
- **동작**: 삭제 확인 후 실행

#### FR-4.5 카드 이동
- **설명**: 드래그앤드롭으로 카드 이동
- **이동 가능**:
  - 같은 리스트 내 순서 변경
  - 다른 리스트로 이동
- **라이브러리**: @dnd-kit

### 2.5 라벨 기능 (P1)

#### FR-5.1 라벨 생성
- **설명**: 보드별 라벨 생성
- **입력**:
  - 라벨 이름 (필수, 1-50자)
  - 색상 (필수, 사전 정의된 10가지 색상 중 선택)
- **저장**: 보드별로 라벨 저장

#### FR-5.2 라벨 목록 조회
- **설명**: 해당 보드의 모든 라벨 조회
- **출력**: 라벨 이름, 색상

#### FR-5.3 카드에 라벨 할당
- **설명**: 카드에 하나 이상의 라벨 추가
- **동작**:
  - 카드 상세 화면에서 라벨 선택
  - 다중 선택 가능
  - 카드 요약에 라벨 색상 표시

#### FR-5.4 라벨 제거
- **설명**: 카드에서 라벨 제거
- **동작**: 라벨 클릭 또는 X 버튼

#### FR-5.5 라벨 수정
- **설명**: 라벨 이름 또는 색상 변경
- **영향**: 해당 라벨을 사용하는 모든 카드에 반영

#### FR-5.6 라벨 삭제
- **설명**: 라벨 영구 삭제
- **영향**: 모든 카드에서 해당 라벨 제거

#### FR-5.7 라벨 필터링
- **설명**: 특정 라벨이 포함된 카드만 표시
- **동작**:
  - 라벨 클릭 시 필터 활성화
  - 다중 라벨 필터 가능 (OR 조건)
  - 필터 해제 버튼 제공

### 2.6 마감일 기능 (P1)

#### FR-6.1 마감일 설정
- **설명**: 카드에 마감일(Due Date) 설정
- **입력**: 날짜 + 시간 (선택)
- **UI**: 날짜 선택 달력 (Date Picker)

#### FR-6.2 마감일 표시
- **설명**: 카드에 마감일 시각적 표시
- **표시 위치**:
  - 카드 썸네일: 마감일 아이콘 + 날짜
  - 카드 상세: 전체 날짜/시간
- **색상 코드**:
  - 초록색: 마감일까지 2일 이상 남음
  - 노란색: 마감일까지 1-2일
  - 빨간색: 마감일 임박(24시간 이내) 또는 초과

#### FR-6.3 마감일 수정
- **설명**: 설정된 마감일 변경
- **동작**: 날짜 클릭 시 Date Picker 표시

#### FR-6.4 마감일 제거
- **설명**: 카드에서 마감일 삭제
- **동작**: "마감일 제거" 버튼

#### FR-6.5 마감일 정렬
- **설명**: 카드를 마감일 기준으로 정렬
- **옵션**:
  - 마감일 빠른 순
  - 마감일 늦은 순
- **적용 범위**: 리스트 내 카드

### 2.7 멤버 할당 (P2)

#### FR-7.1 멤버 초대
- **설명**: 보드에 멤버 초대 (이메일)
- **입력**: 초대할 사용자 이메일
- **동작**:
  - 이메일로 초대 링크 전송
  - 수락 시 보드 멤버로 추가

#### FR-7.2 멤버 목록 조회
- **설명**: 보드 멤버 목록 표시
- **출력**: 프로필 사진, 이름, 이메일

#### FR-7.3 카드에 멤버 할당
- **설명**: 카드에 담당자 지정
- **동작**:
  - 카드 상세 화면에서 멤버 선택
  - 다중 멤버 할당 가능
- **표시**: 카드에 멤버 프로필 아이콘 표시

#### FR-7.4 멤버 할당 해제
- **설명**: 카드에서 멤버 제거
- **동작**: 멤버 아이콘 클릭 또는 X 버튼

#### FR-7.5 멤버별 필터링
- **설명**: 특정 멤버가 할당된 카드만 표시
- **동작**: 멤버 클릭 시 필터 활성화

#### FR-7.6 멤버 제거
- **설명**: 보드에서 멤버 제거
- **권한**: 보드 소유자만 가능
- **영향**: 해당 멤버의 모든 카드 할당 해제

### 2.8 활동 로그 (P2)

#### FR-8.1 활동 기록
- **설명**: 보드/카드의 모든 변경사항 자동 기록
- **기록 항목**:
  - 카드 생성/수정/삭제/이동
  - 리스트 생성/수정/삭제/이동
  - 라벨 추가/제거
  - 마감일 설정/변경/제거
  - 멤버 할당/해제
- **기록 정보**:
  - 누가 (사용자)
  - 언제 (타임스탬프)
  - 무엇을 (작업 내용)

#### FR-8.2 활동 로그 조회
- **설명**: 활동 기록 시간순 표시
- **표시 위치**:
  - 카드 상세: 해당 카드 활동
  - 보드 사이드바: 전체 보드 활동
- **정렬**: 최신 순

#### FR-8.3 활동 로그 필터링
- **설명**: 특정 조건의 활동만 표시
- **필터 옵션**:
  - 멤버별
  - 작업 유형별 (생성, 수정, 삭제 등)
  - 날짜 범위

### 2.9 사이드 패널 (P0 - Day 42 유지)

- **설명**: 카드 클릭 시 오른쪽 사이드 패널 표시

  - 카드 제목 (편집 가능)

## 3. 비기능 요구사항 (Non-Functional Requirements)

### 3.1 성능 (Performance)

#### NFR-1.1 페이지 로드 시간
- **기준**: 초기 페이지 로드 < 2초
- **측정**: Lighthouse 사용

#### NFR-1.2 드래그앤드롭 응답성
- **기준**: 드래그 시작부터 드롭까지 지연 < 100ms
- **목표**: 60 FPS 유지

#### NFR-1.3 데이터베이스 쿼리
- **기준**: 단일 쿼리 < 50ms
- **최적화**: 인덱스 적용, 필요한 데이터만 조회

### 3.2 사용성 (Usability)

#### NFR-2.1 반응형 디자인
- **대상**:
  - 데스크톱: 1920px ~ 1024px
  - 태블릿: 1024px ~ 768px
- **제외**: 모바일 (768px 이하)

#### NFR-2.2 직관적 UI
- **원칙**:
  - 버튼/액션은 명확하게 라벨링
  - 아이콘 + 텍스트 조합
  - 일관된 디자인 시스템 (shadcn/ui)

#### NFR-2.3 접근성
- **키보드 내비게이션**: Tab/Enter/ESC 지원
- **색상 대비**: WCAG AA 기준 충족

### 3.3 보안 (Security)

#### NFR-3.1 인증
- **방식**: NextAuth + Google OAuth
- **세션**: HTTP-only 쿠키 사용

#### NFR-3.2 권한 관리
- **원칙**: 사용자는 자신의 보드만 접근 가능
- **검증**: 서버 사이드에서 권한 확인

#### NFR-3.3 입력 검증
- **적용**: 모든 사용자 입력 sanitize
- **방지**: XSS, SQL Injection

### 3.4 신뢰성 (Reliability)

#### NFR-4.1 데이터 무결성
- **DB**: SQLite ACID 트랜잭션
- **백업**: 로컬 DB 파일 백업 가능

#### NFR-4.2 에러 처리
- **원칙**: 모든 에러는 사용자 친화적 메시지 표시
- **로깅**: 서버 에러는 콘솔에 기록

### 3.5 유지보수성 (Maintainability)

#### NFR-5.1 코드 품질
- **TypeScript**: 타입 안정성
- **Linting**: ESLint 규칙 준수
- **Formatting**: Prettier 사용

#### NFR-5.2 테스트
- **E2E**: Playwright로 주요 시나리오 테스트
- **커버리지**: 핵심 기능 90% 이상

## 4. 사용자 스토리 (User Stories)

### 4.1 P0 (필수 - MVP)

#### US-1: 로그인
- **As a** 사용자
- **I want to** Google 계정으로 로그인
- **So that** 내 보드에 접근할 수 있다

#### US-2: 보드 생성
- **As a** 사용자
- **I want to** 새로운 보드를 생성
- **So that** 여러 프로젝트를 분리하여 관리할 수 있다

#### US-3: 보드 전환
- **As a** 사용자
- **I want to** 보드 목록을 보고 선택
- **So that** 작업 중인 프로젝트를 빠르게 전환할 수 있다

#### US-4: 리스트 관리
- **As a** 사용자
- **I want to** 보드에 리스트를 추가/수정/삭제
- **So that** 작업 단계를 정의할 수 있다

#### US-5: 카드 관리
- **As a** 사용자
- **I want to** 리스트에 카드를 추가/수정/삭제
- **So that** 개별 작업을 추적할 수 있다

#### US-6: 카드 이동
- **As a** 사용자
- **I want to** 카드를 드래그앤드롭으로 이동
- **So that** 작업 상태를 빠르게 변경할 수 있다

### 4.2 P1 (중요)

#### US-7: 라벨 추가
- **As a** 사용자
- **I want to** 카드에 색상 라벨을 추가
- **So that** 카드를 시각적으로 분류할 수 있다

#### US-8: 라벨 필터
- **As a** 사용자
- **I want to** 특정 라벨의 카드만 보기
- **So that** 관련 작업을 빠르게 찾을 수 있다

#### US-9: 마감일 설정
- **As a** 사용자
- **I want to** 카드에 마감일을 설정
- **So that** 중요한 일정을 추적할 수 있다

#### US-10: 마감일 알림
- **As a** 사용자
- **I want to** 마감일이 임박한 카드를 시각적으로 확인
- **So that** 놓치는 일이 없도록 할 수 있다

### 4.3 P2 (개선)

#### US-11: 멤버 할당
- **As a** 팀 리더
- **I want to** 카드에 팀원을 할당
- **So that** 누가 무엇을 담당하는지 명확히 할 수 있다

#### US-12: 멤버 필터
- **As a** 팀원
- **I want to** 내가 할당된 카드만 보기
- **So that** 내 작업에 집중할 수 있다

#### US-13: 활동 확인
- **As a** 사용자
- **I want to** 카드의 변경 이력을 확인
- **So that** 무엇이 언제 바뀌었는지 알 수 있다

## 5. 화면별 상세 요구사항

### 5.1 로그인 화면 (/login)
- **구성 요소**:
  - 로고
  - 서비스 설명
  - "Google로 로그인" 버튼
- **동작**: 버튼 클릭 시 Google OAuth 페이지로 리다이렉트

### 5.2 보드 목록 화면 (/)
- **구성 요소**:
  - 헤더 (로고, 사용자 프로필, 로그아웃, 다크모드 토글)
  - "새 보드 만들기" 버튼
  - 보드 그리드 (카드 형태)
    - 각 보드: 썸네일, 이름, 카드 개수, 최근 수정 시간
- **동작**:
  - 보드 클릭 시 해당 보드 페이지로 이동
  - "새 보드 만들기" 클릭 시 모달 표시

### 5.3 보드 화면 (/board/[id])
- **구성 요소**:
  - 헤더
    - 보드 이름 (편집 가능)
    - 멤버 아이콘 리스트 (P2)
    - 라벨 필터 버튼 (P1)
    - 멤버 필터 버튼 (P2)
    - 보드 설정 버튼 (배경 변경, 삭제)
    - 저장 버튼
  - 리스트 영역
    - 기존 리스트들 (가로 스크롤)
    - "리스트 추가" 버튼
  - 사이드 패널 (카드 상세)
- **동작**:
  - 리스트/카드 드래그앤드롭
  - 카드 클릭 시 사이드 패널 열림

### 5.4 카드 상세 패널 (사이드 패널)
- **구성 요소**:
  - 제목 (편집 가능)
  - 설명 (편집 가능, 마크다운 지원)
  - 라벨 섹션 (P1)
    - 기존 라벨 표시
    - 라벨 추가/제거 버튼
  - 마감일 섹션 (P1)
    - 현재 마감일 표시
    - Date Picker
    - 제거 버튼
  - 멤버 섹션 (P2)
    - 할당된 멤버 표시
    - 멤버 추가/제거 버튼
  - 활동 로그 (P2)
    - 시간순 활동 리스트
  - 삭제 버튼
  - 닫기 버튼 (X)

### 5.5 모달들
- **보드 생성 모달**
  - 입력: 보드 이름, 배경 선택
  - 버튼: 생성, 취소
- **라벨 관리 모달** (P1)
  - 라벨 목록
  - 새 라벨 생성 폼
  - 라벨 수정/삭제
- **멤버 초대 모달** (P2)
  - 입력: 이메일
  - 버튼: 초대, 취소

- API 제공 없음
