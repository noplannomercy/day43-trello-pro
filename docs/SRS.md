## SRS

### 개요
싱글 보드 칸반 앱. 리스트와 카드를 관리하고 드래그앤드롭으로 카드 이동.

### 핵심 기능

1. 보드 (Board)
- 싱글 보드 (1개만)
- 보드 제목 표시

2. 리스트 (List)
- 리스트 CRUD (생성/수정/삭제)
- 리스트 순서 고정 (드래그 없음)
- 기본 리스트: To Do, In Progress, Done

3. 카드 (Card)
- 카드 CRUD (생성/수정/삭제)
- 카드 제목 필수
- 카드 설명 선택
- 드래그앤드롭으로 리스트 간 이동
- 같은 리스트 내 순서 변경

### 기술 스택
- Next.js 15 + TypeScript
- SQLite + Drizzle ORM
- shadcn/ui
- @dnd-kit (드래그앤드롭)

### 페이지
- / (메인 보드 페이지)

### 제외 범위
- 멀티 보드
- 사용자 인증
- 라벨/마감일/체크리스트
- 실시간 동기화
