## Phase {N} 실행 (Frontend)

### 실행 방식
coder-expert 서브에이전트 배포하여 구현

### 구현 규칙
1. Phase {N} 섹션 전체를 먼저 읽고 시작
2. "Files to Create" 목록 순서대로 구현
3. COMPONENTS.md의 Props/인터페이스 정의 참조
4. Context7 MCP로 최신 문서 참조 (Next.js, shadcn/ui, Recharts, date-fns)
5. API 호출은 fetch로 직접 호출 (hooks 내부에서)

### 빌드 검증
파일 3개마다:
```bash
npm run build
```
- 에러 0개여야 다음 진행
- 에러 발생 시: 즉시 수정 → 재빌드 → 계속
- 동일 에러 3회 실패 시: 보고 후 중단

### 화면 테스트 (Phase 완료 후)
npm run dev 실행 후 IMPLEMENTATION.md Phase {N}의 "화면 테스트" 항목 검증:
- 페이지 접근 가능 (에러 없음)
- 목록 조회 정상
- 등록/수정/삭제 동작
- 에러 케이스 처리
